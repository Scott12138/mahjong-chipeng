# docs/verify/S1 —— S1 阶段验证记录

## 这是什么

S1（框架骨架 + 页面切换）完成时，用**无头点击冒烟测试**跑出来的截图与日志：

| 文件 | 内容 |
|---|---|
| `01-菜单页.png` | 菜单页初始态 |
| `02-关卡页（含点击提示）.png` | 点击「开始游戏」后切到关卡页 |
| `03-返回菜单.png` | 点「返回」切回菜单页 |
| `console.log` | 引擎控制台输出（含 `✅ 引擎可见尺寸 = 设计分辨率 720×1280` 自检行） |

用途是**证明功能跑通**（页面能构建、能切换、能点击），**不是视觉验收**。

---

## ⚠️ 风格说明（重要）

这批截图的画面是 **S1 期的原始默认风格**：

> 墨绿底色(深绿渐变) + 金色立体描边标题 + 红色圆角按钮

**它已经被废弃，不是定稿视觉。** 后续美工定稿为**国潮描边**风格（宣纸底 + 墨线双框 + 朱红角花 + 硬直角 + 真牌配色）。

📌 **正确视觉请以 `docs/design/guochao-tiles.html` 与 `docs/design/screens/` 为准。**
📌 设计规范、色板、美工协作约定见 **`docs/design/README.md`**。

---

## 为什么保留而不删除

本项目硬要求「**每次修改都能回溯**」。这批图是 S1 里程碑的真实证据，
删除会破坏历史链条，因此**原样保留**，仅在此加注说明其风格已过时。

等到**国潮美工落进引擎代码后**，重跑一次冒烟测试产出新截图，
届时可把这批移入 `archive/` 并改名标注版本（如 `01-菜单页_S1-original-style.png`）。
