# S13 · BGM 候选（拍板用）

5 段**程序化合成的纯音乐**，全部由本仓库 `game-4-mahjong/tools/make-bgm.py` 产出，
零素材下载、无版权风险、可无缝循环。参考对象是《抓大鹅》的「轻快电子旋律 · 欢快治愈」。

## 怎么听

打开 **`BGM候选-试听.html`** —— 单文件、音频已 base64 内嵌，双击即可，不需要联网、不需要起服务。
每张卡片下方有「就选它」按钮，选完把编号告诉我即可。

也可以直接播 `A-跳跳糖.m4a` 等文件（拖进音乐播放器）。

## 体检数据（复现命令见下）

| 候选 | 时长 | 体积 | RMS | 波峰因数 | 音头/秒 | 零交叉率 | 循环接缝 |
|---|---|---|---|---|---|---|---|
| A 跳跳糖 | 30.00s | 244K | −14.7dB | 3.81 | 7.17 | 2819 | 1.41 |
| B 鹅步快跑 | 27.43s | 227K | −16.0dB | 4.43 | 4.19 | 5240 | 0.87 |
| C 茶馆电音 | 34.29s | 281K | −14.3dB | 3.64 | 3.30 | 1423 | 2.71 |
| D 牌桌弹珠 | 30.97s | 255K | −16.2dB | 4.50 | 6.91 | 4024 | 0.56 |
| E 夜灯摇摆 | 32.54s | 268K | −15.1dB | 3.96 | 4.09 | 2767 | 0.83 |

- **音头/秒** = 每秒音头数（"动感密度"）；**零交叉率** = 亮度的廉价代理（越高越"电/亮"）。
- **循环接缝** = 循环点的样点跳变 ÷ 曲内强拍跳变中位数。**都 ≤ 曲内最强强拍**，
  即循环点听起来跟曲中任何一个强拍一样顺，不会"咔"一下。

## ★ 已拍板并接入游戏（2026-10-01）

**用户选定：C · 茶馆电音**，已作为局内 BGM 接入。

| 项 | 值 |
|---|---|
| 落盘 | `game-4-mahjong/assets/resources/audio/bgm.m4a`（281.0K / 34.286s / 44.1kHz 单声道 AAC） |
| uuid | `41f54655-3174-55bb-9467-34955060974c`（uuid5 派生，固定不变） |
| 加载路径 | `audio/bgm`（`AudioService.BGM_PATH`，**不带扩展名**） |
| 音量 | `CFG.AUDIO.BGM_GAIN = 0.30`（≈ 比人声 `peng 0.95` 低 10dB） |
| 包体 | 3,482,629 字节 = **3.32 MB**，红线 4MB，**余量 695 KB** |

**起播范围**：主菜单不播；**选关页 + 局内**播（各自 `onBuild` 调 `playBgm()`，幂等）；
回主菜单淡出停止（`BGM_FADE_MS = 420`）。

**起播点为什么必须写 `onBuild`、绝不能写 `onEnter`** —— 本项目最容易踩的音频坑：
`PageManager.open` 里 `onEnter` 是 `setTimeout(duration + 20ms)` 之后才调的，**已经出了
用户手势的调用栈**，浏览器 / 微信的 autoplay 策略会**静默拦截**（不抛异常、日志也无痕，
表现只是"没声音"）。而 `onBuild` 由 `open` **同步**调用、`open` 又由 点击 → `goto`
同步触发 ⇒ **在手势栈内** ✅

**换曲**只改 `tools/make-bgm.py` 顶部的 `CHOSEN`，再跑：
```bash
python3 tools/make-bgm.py --install     # 消费已验收的 out m4a，不重新合成
```
🔴 别手工拷文件 —— 会丢 `.meta` 的 uuid，Cocos 里表现为"音频莫名为空"。
`--install` 刻意**不重新渲染**：用户拍板时听的就是那个文件，重渲染等于让"拍板的"
和"上线的"变成两个东西。

**验收**（日志：`docs/verify/S13/05-BGM-无头验收日志.txt`）：
`BGM 就绪 1 次` ／ `BGM 起播 2 次`（返回菜单后确实停了、再次进入重播）／ 控制台 **0 报错** ／
`bgm.m4a` 按 md5 出现在 `build/wechatgame/assets/resources/native/41/41f54655….m4a`。

## 复现

```bash
cd game-4-mahjong
python3 tools/make-bgm.py                 # 合成 5 段 → 本目录
python3 tools/make-bgm.py --page          # 顺带重建试听页
python3 tools/make-bgm.py --only A,C      # 只出指定段
python3 tools/make-bgm.py --stems         # 打印各声部"活跃段 RMS vs 目标"
python3 tools/make-bgm.py --no-trim       # 关掉自动配平，听原始平衡
python3 tools/make-bgm.py --install       # 把 CHOSEN 那段装进游戏（bgm.m4a）
```

⚠️ **重跑两次 m4a 的 md5 完全一致**（已实测）：脚本用固定种子 + 复用
`make-sfx.py` 的 `zero_container_times()` 清容器时间戳。所以本目录可以直接进版本控制，
"这次到底改了哪一段"看得清清楚楚。

## 备注

- **A / B / D / E 四段落选候选保留在本目录**，没有进游戏包、不占首包体积。
- 全部为**纯音乐**（无任何人声/歌词）。
- 这几段是**合成 demo**，不是最终混音成品 —— 若后续要提音质，
  改 `make-bgm.py` 里 `afconvert` 的 `-b 64000` 一档即可（体积同步变化）。
