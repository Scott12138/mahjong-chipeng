## 关键教训（已回写技能）

1. ImageGen `revise` 图生图**不保持输入图尺寸**（1536 竖版 → 1024 方形），改局部文案前要有心理预期。
2. 工具水印固定在右下角，**会压住画面右下角的元素**（本例正好是方印）——出图后必须放大目检水印覆盖了什么。
3. 在有 vignette 渐变的背景上，**平色填充必露馅**，要用双锚点线性插值 + 轻噪声。
4. 印章/带纹理元素的局部重建：镜像会连字一起镜像；优先找"同风格孪生图"借完整部件。
5. 本地 PIL 精准修图（改字/去水印）比图生图 revise **更可控**：不动画面其它部分、不耗积分。
