## 三、风格令牌（可直接抄进 `CFG.COLOR`）

### 色板

| 令牌 | 值 | 用途 |
|---|---|---|
| `paper` | `#F2EADA` | 页面纸底（不用纯白） |
| `paper2` / `face` | `#FBF6EA` | 牌面 / 面板底色 |
| `paperDark` | `#EFE6D2` | 纸底暗层 |
| `faceDim` | `#EDE6D4` | 被压住的牌面 |
| `ink` | `#22201C` | 墨 · 主描边 |
| `vermilion` | `#C4362B` | 朱红 · 角花（界面用） |
| `gold` | `#C9A227` | 金 · **仅界面**（标题描边 / 消除反馈 / 广告角标高光） |
| `inkMid` | `#57503F` | 次级文字 |
| `inkSoft` | `#8E8571` | 弱化文字 |
| `lock` | `#B9B09A` | 锁定态 |

### 真牌三色（**与界面红分开，这是本稿的关键**）

| 令牌 | 值 | 用于 |
|---|---|---|
| `blue` | `#2338A0` | 万子中文数字、筒族蓝、条 7 中列 |
| `red` | `#B02A1E` | 「萬」字、筒族红、条 5 中 / 条 7 顶 / 条 9 中列 |
| `green` | `#2E6B45` | 条族主色、筒族绿 |

派生：
- **浅调** `LIGHT = tint(色, 0.50)` —— 圆饼中间那一环（**真牌不用白心**）
- **最深** `DEEP = deep(色, 0.30)` —— 圆饼最外那道细深环，少了它圆饼会「飘」
- **降饱和替身** `DIM = { blue:#8A8C9E, red:#A08279, green:#8A9A8C }` —— 被压住时用

> 界面的红（`#C4362B`）偏亮，是「颜料」；牌面的红（`#B02A1E`）偏沉，是「墨」。
> 两者放一起是层次，不是撞色。**不要合并成同一个红。**

### 字体与字号

| 用途 | 字族 | 字号 × 字重 |
|---|---|---|
| 牌面数字（蓝） | 宋体族 | **64 × 800** |
| 牌面「萬」（红） | 宋体族 | **58 × 800** |
| 页面主标题 | 宋体族 | 76 × 800，墨色 + 金描边 5px |
| 副标题 | 系统无衬线 | 30 × 400，字距 5 |
| 按钮 | 系统无衬线 | 44 × 700，字距 10 |
| 正文 / 提示 | 系统无衬线 | 24–26 × 400 |

- **牌面用衬线体、界面用无衬线**：牌面衬线是「萬」字的真实字形（明朝体骨架）。
- 引擎**不打包字体**，靠平台字体回退兜底。
- 字体串固定为：`'Songti SC','STSong','SimSun',serif`

### 形态规则（四条，缺一条就不「国潮」）

1. **宣纸底** —— 不用纯白，一律带米黄暖灰。
2. **墨线双框** —— 外粗（3.2）内细（1.1）两道，中式装帧骨架，「描边」二字的来源。
3. **朱红角花** —— 内框四角各一段朱红折线（回纹极简版），8 条短线段，成本极低、国潮味最重。
   锁定态**不画角花**。
4. **硬直角** —— 圆角压到 **3–7px**。这条是把「玩具感」换成「器物感」的关键。

### 硬约束（改参数前必读）

- **牌面零金** —— 已拍板。真牌没有金，加了会削弱三族区分度。
- **竹节**：中央竖向高光（宽 0.26w）**必须贯通**；侧缺口宽**必须 < 0.37w**。
  一旦高光 + 左右缺口接起来把整根切满，竹子就变成「绷带」（这个坑踩过两次）。
- **万子纵向居中**：数字 `y=72` / 萬 `y=144`（牌面坐标系 132×176，中心 y=88）。
  上下留白各约 12.7px。**这两个数是量出来的**，别凭手感改。
- **坐标系**：牌面内部固定 **132×176**，绘制时按 `实际牌宽 / 132` 等比缩放。
