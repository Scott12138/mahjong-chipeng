方案 A ·「宣纸墨戏」—— 不加元素，把这一页做高级

三份提案里的最低成本、最静的一份。它不换体系、不加题材元素、不碰 27 张牌面， 回答的是一个问题：不靠加东西、不靠换皮，这页能不能做高级？ 具体动作是三件 —— 顶部换成一条极细的进度刻度状态条取代选关页、中央把三张小牌换成一枚 440px 的主牌稳坐在墨色圆台上、 底部一枚朱红大主按钮 + 一颗小「重玩」；色调上把金从环境色降为事件色，并引入一个本项目从未出现过的冷色 · 靛青， 用在「已过的刻度」与「中轴竖缝」两处结构位上 —— 这就是本方案「色调变了」的全部抓手。

技术前提：Cocos Graphics + Label，零贴图 色彩基底：沿用现有 CFG.COLOR（纸 #F2EADA / 墨 #22201C / 朱红 #C4362B） 新增冷色：靛青 #31506E（仅 2 处结构位） 金：从常驻标题描边 → 一次性通关印 成本等级：低 体积增量：0 KB（零贴图）

主牌为什么是 440 而不是「接近满屏宽」的 588 —— 这是量出来的，不是拍的。 牌的视觉占位不是牌体本身，还要算上立体的那一圈（drawSolid 的投影 + 厚度壁）。 以牌宽 w 为基准，用现有 CFG.TILE.SOLID 的参数（DEPTH 27 / SIDE_DX 6 / SHADOW_DY 11 / SHADOW_SPREAD 4 × 3 层）折算： 视觉宽 ≈ 1.10 w、视觉高 ≈ 1.534 w（已在稿子里用 getBoundingClientRect 实测复核： w＝440 时视觉框 484 × 675，与算式一致）。 内框可用的纵向预算只有 +453 → −300 ＝ 753px（顶部要给刻度条留呼吸、底部要给按钮留呼吸）， 于是 wmax ＝ 753 / 1.534 ≈ 491。取 440 是给四周各留出至少 40px 呼吸 —— 440 时视觉高 675，上留 40（刻度条下沿 → 牌顶）、下留 40（牌底 → 主按钮上沿）。 若真做到 588 宽：视觉高 902，超出预算 149px，牌底必然被主按钮压住。 所以「接近满屏宽」在本页的正确解法是把横向留白压到 52 单位／边（视觉宽 484 ＝ 内框宽 588 的 81.6%）， 而不是把牌撑满 —— 留白是这张牌显大的原因，一点都不能再让。

①-b · 选关页删掉之后：三个问题的三个答案

选关页一删，首页就同时承担了「继续」「重玩」「清空」三件事。下面是单一主张，不是选项清单 —— 三条都落在已经存在的元素上，不新增任何页面、不新增任何浮层。

主张 · 三条

  1. 从哪继续 → 底部 420×132 朱红主按钮。文案随存档自动三态：
    全新存档 → 开 始 · 第 1 关；
    已过 N 关（N<4）→ 继 续 · 第 N+1 关；
    4 关全通 → 再 战 · 第 4 关（提示行同时换成「已全部通关 · 最佳 02:14」）。
    「当前关」＝ clearedCount + 1，直接由现有 SaveService 算得出，不需要改存档结构。
  2. 怎么重玩 → 主按钮右侧那颗 88×88「重玩」小方，点一下原地换装。 不跳页、不弹层：主按钮文案变成 重 玩 · 第 k 关，主按钮左右内侧各出现一枚 44×44 的 「‹ ›」小箭头（贴在按钮内部、宽度上不占新空间），只在已通关的关之间循环； 同时「重玩」小方翻面成「继续」，点它退回继续态；4 秒无操作自动退回。 这样重玩不产生任何新的纵向占用，也不会退化成第二张选关页。
  3. 怎么清空 → 长按右下角朱红方印 1.5 秒。 进度为 0 时此入口锁死且不给任何提示（没东西可清就不该有入口）。 长按期间方印四周长出一圈四段折线做进度反馈（不用圆弧 —— 硬直角体系里不该出现圆弧）， 松手即取消。成功时方印缩到 0.7 再弹回 1.0（240ms backOut）， 同时顶部 4 枚刻度从右到左依次褪回未过态（每枚错峰 60ms）。 ——「印 ＝ 存档」是这个动作的语义锚点。
一级／二级重心（≤2 处） 三级：宣纸／灰米，不参与争注意力 靛青：只出现在刻度与竖缝
为什么不是「长按重玩」也不是「独立清空按钮」。 清空进度是不可逆的破坏性操作，它必须有一个「慢」的手势；而重玩是可逆的轻操作，它应该快。 所以：轻操作用点（重玩小方），重操作用长按（方印） —— 手势的时长差异本身就是一次防误触设计， 比弹一个「确定要清空吗？」的二次确认框更安静，也更符合这一页的气质。

必须换的那一处，说清「原值 → 新值 + 为什么」：
原值：GOLD #C9A227 用在页面主标题上 —— 76px 墨字 + 5px 金描边，常驻在首页最显眼的位置， 是整份视觉稿里金用量最大的一处（约 2.4 万 px² 的线性笔画）。
新值：值不变（仍是 #C9A227），但位置与生命周期全变 —— 只在通关瞬间那枚 96×96「过」字印上出现一道 3px 描边，存在时长 ≤ 1.6 秒，页面回到首页时已经消失。
为什么必须换：金是「朱红 + 墨 + 金」这三根柱子中唯一一根纯装饰的柱子 —— 红承担"行动"语义、墨承担"结构"语义，金什么都不承担，只负责"贵气"。 而「墨字金边」在中文视觉里是牌匾 / 招牌 / 彩头的语言，正是 docs/design/README.md §7 记的那条未解除风险的直接来源。 把它从常驻环境色降级为一次性事件色，等于在画面上直接拆掉了三柱结构的一根 —— 这不需要改一个色值，只需要改它出现的次数和时长，是这套体系里性价比最高的一次合规动作。

§3 动效分镜 三组关键帧 + 参数表 · 「魔性」必须落在具体数字上

三组动效全部落在引擎能动的边界内：位置 / 缩放 / 旋转角 / 透明度，加上重绘 Graphics。 粒子总计 24 枚（通关 16 + 失败 8），全部塞在各 1 个 Graphics 节点里逐帧 clear() + 重绘 —— 对比参照物：现有工程最重的一帧是 96 张牌各一个 Graphics，这里 2 个 Graphics 画 24 个方块，远低于那个量级。 粒子数刻意停在 16 与 8，就是为了一次都不要碰 40 的上限。

③-A · 开场「一滴墨」 · 总时长 1500ms

它和现有的「牌从下方涌现」是什么关系：取代，不是叠加。
现有实现（CFG.MOTION 十六节，S17 方案 B）：每张牌起点在自己目标位置正下方 1.2 个牌高、 起始缩放 0.45、错峰成束、落位挤压回弹、整段 1.6s。
为什么取代：新开场的第 ⑥ 帧本身就承担了「牌堆出现」这件事 —— 墨圆从中间裂开、露出棋盘的那一刻， 背后必须已经有东西。若在这之后接 1.6s 的涌现，玩家会看到「棋盘已经在了，牌又冒出来一次」， 同一件事讲两遍，且总等待变成 2.5s+，超出"小开场动画"的预算（本方案把整段压进 1.5s）。
SPROUT 的手感一条都不丢，只是搬了家：它的三个要害 ——「由小变大」「落位过冲」「错峰」 —— 被迁进「墨圆裂开」那一拍：牌堆容器在 260ms 里从 1.06 缩到 1.00（复用 PAGE.ENTER_SCALE_FROM 的推镜语言）， 并在落定时复用 SPROUT_SQUASH 的 0.24s 挤压回弹。 即：把 1.6s 的表演，收进 260ms 的一拍里。
唯一要接受的变化：涌现是"一撮一撮往上顶"的过程感，开裂是"一下子全亮"的揭示感。 这是本方案在叙事上的取舍，如果你更想保留过程感，可把第 ⑥ 帧的容器动画替换回 SPROUT —— 两者互不影响，是同一个接缝上的二选一。

§5 本方案的自律规则 留白多但不能空 —— 靠比例撑住，不靠加元素

首页是这一页最危险的地方：元素一少，就容易从"高级"掉进"空"。 防掉下去的办法不是再塞点东西，而是给这页立几条能被检查的硬指标 —— 下面每一条都是"可以拿去反驳设计师"的那种，不是"要有呼吸感"这种空话。

规则一 · 视觉重心只允许 3 级、一级只允许 1 个

  1. 一级 · 1 个：中央主牌。允许对比度 ≥ 4.5:1、覆盖面积 ≥ 60000px²、允许使用饱和色。 全页任意时刻只允许有 1 个一级 —— 这条是"主牌能大"的前提：如果同时还有第二个大块面，牌就必须缩小。
  2. 二级 · 2 个：主按钮、顶部「当前关」那一枚刻度。允许 ≥4.5:1、面积上限 60000px²、允许朱红实心。
  3. 三级 · 其余全部（书名、已过计数、重玩小方、圆台、竖缝、提示行、页脚）：对比 ≤3:1 或 面积 ≤3000px²， 且不得出现朱红或靛青的纯色。
    唯一豁免：右下角方印用朱红，但面积锁死 ≤2704px² 且必须贴页框角 —— 靠位置把它从"重心"降级为"印记"。

  4. 反过来说：任何新增的朱红元素，都必须先从这里扣。想加一枚红角标？先把主按钮缩到 400 宽（省 2640px²）。

规则三 · 线的配额

  1. 竖线全页只允许 1 条（中轴竖缝）。它是眼睛的轨道，同时也是"参考图2 那道缝"的唯一继承者。
  2. 横线组全页只允许 1 组（刻度槽 + 4 枚刻度）。除它以外，页面上不允许出现任何横线 —— 包括分隔线（旧版的 DIVIDER_Y 在本方案里被删掉了）。
  3. 椭圆只允许 4 个（圆台 3 层同心淡出 + 1 道靛青环，环与最外层共参数）。
  4. 加一条线，先删一条线。这条是这一页不崩的唯一保险。

规则四 · 呼吸的下限（任一被压破，优先删元素，不要压间距）

  1. 主牌四周 ≥ 36px。这是它"大"的必要条件 —— 撑满就等于没有留白，而留白正是这张牌显大的原因。
  2. 书名行 → 刻度条：28px；刻度条 → 主牌顶：57px。
  3. 圆台底 → 主按钮顶：36px；主按钮底 → 提示行：32px；提示行 → 页脚：19px。
  4. 以上任何一条不足时：先删三级元素（页脚、提示行都可以整行删），绝不压缩主牌的四周留白。
禁止清单（本方案一条都不许破）： ① 描边叠 3 层以上（会立刻读成"厚描边"而不是"结构"）； ② 纯黑 #000000（墨是 #22201C，带一点暖）； ③ 任何渐变 / 模糊 / 阴影 / 图层混合（Graphics 本来也不支持）； ④ 装饰性文字 —— 任何一个字都必须有信息量； ⑤ 第三个饱和色相（现有 朱红 + 靛青 + 真牌三色（牌面内）已经是上限，页面里只许前两个）； ⑥ 在牌面上加任何东西（27 张牌是已定稿资产）； ⑦ 圆形以外的"软"形状 —— 圆台是椭圆、墨晕是圆，除此之外全部是硬直角圆角矩形（3–7px）。

一句话总结

关键词：留白 · 一枚主牌 · 靛青点睛。 方案 A 不换体系、不加题材元素、不碰 27 张牌面，只做三件事 —— ① 顶部用一条 252px 的极细刻度状态条取代整个选关页（4 枚刻度，已过＝靛青 / 当前＝朱红高 8px + 全条唯一的小三角 / 未到＝墨 α0.20）； ② 中央把三张 104px 的小牌换成一枚 440px 的主牌坐在墨色圆台上（它是本关的代表牌，点开始之前就把主角交代完）； ③ 底部一枚 420×132 朱红主按钮 + 一颗 88×88「重玩」小方，三个问题（继续 / 重玩 / 清空）全部落在已有的元素上，不新增任何页面。

色调上真正"变了"的只有两个动作：把金从常驻环境色（76px 标题的 5px 金描边，约 2.4 万 px²）降级为一次性事件色 （通关那枚 96×96「过」印上的 3px 描边，存在 ≤1.6 秒）；引入一个棋牌色板里没有的冷色相 · 靛青 #31506E， 只用在「已过的刻度」与「中轴竖缝」两个结构位上 —— 它不出现在任何文字里（暗光下会向黑靠）， 也不参与任何语义判断（不承担"这是第几关"的唯一信息）。 这一冷一热的对位，就是本方案"不抄参考图1、但用了它的布局骨架"的全部交代。

成本等级：低。净变化约 +250 行 / 0 KB 包体 / 7 个新绘制基元 / 删掉一个页面（选关页 −240 行）/ 存档结构一个字不改（只加一个 3 行的只读 getter）。 本方案不解除 README §7 记的那条合规风险 —— 它只做完了"降低环境暗示"这一半， 另一半在牌面与题材层面，需要单开一稿。
