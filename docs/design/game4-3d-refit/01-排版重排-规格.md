## 一、为什么要重排：4 处越界

现状（`docs/verify/S18/shots/03-局内-去术语文案.png`）实测，元素越过朱红内框：

| 位置 | 越界情况 | 证据 |
|---|---|---|
| **A 顶部整条** | 标题 / 「?」/「不限时」骑在内框上边线（y 86）上 | RULE_BTN_Y=531、SIZE=48 → 上沿 85，压线 |
| **B 第二行** | 「已清 0 / 12」与提示语两端戳出内框左右边 | ROW_X=294 > 内框 288 |
| **C 槽位条 + 道具栏** | 横跨 x 9~710，**左右各越界 57px** | SLOT_BAR_W=700、道具栏 4×166+3×12=700 |
| **D 返回 / 重玩** | 骑在下边线上，越界 50px | BACK_BTN_Y=−600 → 下沿 −628，内框底 −554 |

根因：**S18 新增的「重玩」小方（88px）与道具栏把整条竖向预算推穿了页框下边线**。
CFG 里只写了「改这里任何一个 Y 都要回头检查这一条链（页面内框顶边 554）」——
上半条链有人管，**下半条没人管**。

## 二、版心（本规格的唯一几何依据）

底图换成 R3 后，页框由贴图提供。实测 R3 底图：

- **外框** x 48 / 671，y 76 / 1200
- **内框** x **65 / 653**，y **96 / 1180**

换算到设计坐标（原点 = 屏幕中心、y 向上，`px = 360 + x`、`py = 640 − y`）：

| | 设计坐标 |
|---|---|
| 内框 | x ∈ [−295, 293]，y ∈ [−540, 544] |
| **版心**（内缩 22） | **x ∈ [−272, 272]（宽 544），y ∈ [−518, 522]** |

> 原工程页框 `FRAME_INSET=66` → x 66/654、y 86/1194，与 R3 底图的内框**只差 1~14px**，
> 所以底图可以直接替换；**但引擎必须删掉自己原先画的页框与角花**，否则重影。

### 对齐轴

**四条通栏元素（细墨线 / 进度条 / 槽位条 / 道具栏）左右边界一律 −272 / +272**，
再加上顶部信息条（标题左对齐 −272、计时右对齐 +272）—— 这就形成了页面的**主对齐轴**。
现状这四处左边界分别是 −294 / −294 / −350 / −350，**四个都不一样**，所以看着散。

### 补：顶部信息条的新规格（「?」→「规则」）

**为什么不能继续用「绝对居中」**：旧稿那颗圆「?」是 42×42、绝对居中于 x = 360；
换成汉字两个字后最窄要 88 宽，居中展开成 316~404，而关卡名（宋体 30 + 3px 描边）
的右边界在 **321** —— 只剩 9px，**必撞**。

**新做法**：整条用**弹性三段**（左对齐组 + 右对齐组），把余量**均分**给两处间隙：

```
[ 关卡名 ]        ⟵ 自由 ⟶        [ 规则 ]        ⟵ 自由 ⟶        [ 不限时 ]
 88 ──────────── 321     60      381 ── 478     59      537 ────── 639
```

于是「关卡名右边界 → 规则钮」与「规则钮 → 计时左边界」**永远相等**，
关卡名再长也只是把间隙压缩 —— **结构上不可能重叠**。

| 项 | 值 |
|---|---|
| 「规则」钮 | **92 × 46**，圆角 15，边框 3px 墨色，纸白渐变 |
| 字号 | **28**（原「?」为 22，放大一档）· 宋体 · 字距 2 |
| 形制 | **圆角方**（与底部「重玩」同形制）—— 两个字塞不进圆钮 |
| 纵向 | 上沿 y = 118px（design +522），距朱红内框上边线（96px）24px；下沿 164px，距细墨线（180px）16px |
| 分组间距 | 关卡名与规则钮之间固定 **24px**（同组），然后整组左对齐 −272 |

实测证据：`顶部条-规则钮校验.png`（2.2× 放大 + 三段包围盒 + 间隙标注）。

> ⚠️ 引擎是 Cocos，没有 flex。落地时按「**标题组左对齐 → 规则钮紧随 24px → 计时右对齐**」
> 用 Label 的 `contentSize.width` 动态算规则钮 x 即可；标题宽度上限 = 544 − 92 − 93 − 48 = **311px**
> （宋体 30 约 10 个汉字），超了就把标题字号降到 26。

## 六、本轮踩的三个坑（都已修）

1. **按钮框选错区间** —— 第一次把**三张牌横切了一刀**（命中的红色其实来自牌上的「萬」字与筒饼红圈），
   真按钮却完好。修法：加包围盒**形态自检**（宽 > 半屏、高宽比 0.10~0.45）。
2. **「整行均值」判干净纸底会骗过自己** —— 居中排版文字行的均值仍接近纸色，
   导致**提示行文字被卷进纹理源**，擦除区浮出字影与红色角花残片。修法：改**暗部 8% 分位数**判据。
3. **同一个变量被用在两个地方** —— 规则页的整屏背景误传了「面板内容层」图（470×674），
   被 `.bgimg{width:100%;height:100%}` **拉成整屏**，案例③就被放大铺到面板外。
   另外案例层图片必须夹在「面板本体」与「所有文字」之间，否则标题被盖住（踩了两次）。
